# Changelog

Все значимые изменения InfoLake фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии соответствуют файлу `VERSION` в корне репозитория.

## [1.0.0] — 2026-07-26

### Добавлено
- Переключаемые слои карты: «Дороги и автомагистрали», «Границы государств (акцент)».
- Вкладка отчётов «По объектам» с библиотекой шаблонов и деревом выбора по странам.
- Production-развёртывание: `docker-compose.server.yml`, скрипты обновления с автобэкапом и откатом (`infolake_update_vX.Y.Z.tar`).
- Страницы ошибок frontend (404, ErrorBoundary) и backend (404/500 при `DEBUG=False`).
- Руководство администратора и инструкция первого запуска (`PRODUCTION_LAUNCH.md`).

### Исправлено
- Утечка таймеров анимации зон действия на карте.
- Лимиты памяти frontend/backend и production-запуск без bind-mount (снижение риска зависания Docker/WSL2).

### Изменено
- `DEBUG` в Django читается из `backend/.env` (для production — `DEBUG=False`).
- Оффлайн-скрипты по умолчанию поднимают production frontend.
