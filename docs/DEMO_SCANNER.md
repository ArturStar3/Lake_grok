# Художественная сцена «Сканирование документов»

В редакторе демонстрации откройте **Художественный режим**, создайте пресет
и выберите вариант оформления **Сканирование документов**.

1. Добавьте изображения PNG, JPEG или WebP в инспекторе справа. Можно выбрать
   несколько файлов сразу, максимум 40. Стрелки меняют порядок очереди,
   крестик убирает изображение из сцены.
2. Загрузите DOCX с текстом итогового документа. Лимиты: 10 МБ файла,
   60 000 символов и 600 абзацев, включая содержимое таблиц.
3. Выберите побуквенное проявление, перебор букв или печатную машинку.
   Настройте скорость текста и диапазон времени одного прохода сканера.
4. Проверьте встроенный предпросмотр или нажмите **Просмотр** для показа
   в проигрывателе. Сохраните сценарий и включите пресет в программу
   как художественный такт. Для полного показа оставьте автоматическую
   длительность такта; заданная вручную длительность может обрезать сцену.

Этап карты для этой сцены не требуется. Одновременно видны около четырёх
изображений (точное число зависит от высоты экрана); они сканируются
параллельно: сначала сверху вниз, затем обратно. Скорость каждого прохода
выбирается случайно в заданном диапазоне. Изображения вне видимой области
ожидают своей очереди. После перелёта изображения к листу очередь плавно
подтягивается, а отработанное изображение возвращается в её хвост, пока
формирование текста не завершено. Следующая порция текста становится доступна
для анимации после каждого переноса.
Порции делятся по числу источников; распознавание изображений (OCR) не выполняется.

После заполнения листа запускается финальный перенос: в очереди остаются
только документы, видимые в этот момент. Каждый из них заканчивает
сканирование и перелетает к листу; новые документы в видимую область больше
не подставляются. Сцена завершается только после этого, с пустой областью
очереди.

Пауза проигрывателя останавливает сканирование, перенос и появление текста.
Повторный запуск начинает сцену заново. Длинный лист прокручивается к текущей
позиции печати; после завершения его можно прокрутить вручную. Учитывается
системная настройка уменьшения движения.

Из DOCX сохраняются порядок абзацев и таблиц, выравнивание, отступы,
межстрочные интервалы, основные стили шрифта, размеры и цвета, верхние
и нижние индексы. Простые списки преобразуются в текстовые маркеры.
Это не точная копия страниц Word: колонтитулы, рисунки, сложные списки,
объединения ячеек и разметка страниц не воспроизводятся. Отсутствующие на
устройстве шрифты заменяются системными. В редакторе это ограничение показано
рядом с загрузкой DOCX.

Обработка выполняется локальным backend через
`POST /api/v1/demo-scenarios/import-scanner-document/` (multipart-поле `file`)
с проверкой права редактирования демонстраций. Исходный DOCX не сохраняется:
структурированный текст и допустимые стили хранятся в JSON пресета
`tableau.presets[].scanner`. Изображения используют существующее хранилище
`demo-tableau-media`. Внешние ресурсы, HTML из документов, новые зависимости
и миграции базы данных не требуются.
