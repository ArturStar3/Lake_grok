# Демонстрация возможностей карты

Сценарий демонстрации собирается из трёх слоёв:

1. **Этап** — шаблон вида карты: камера, объекты, события, зоны, текст, анимации.
2. **Мультиэкран** — раскладка слотов; на каждый слот назначается один этап.
3. **Программа** — таймлайн показа: какие этапы и мультиэкраны идут друг за другом, как входят и выходят.

Сценарии хранятся на сервере и доступны всем, у кого есть право **«Сценарии демонстрации»**.

Блоки программы переключает докладчик — стрелками, пробелом или пультом-презентером, как в PowerPoint. Внутри этапа такты (камера, объекты, подпись) могут идти по таймеру. Можно вернуться назад: показ восстановит нужный блок.

Готовый тестовый сценарий инструментов карты: **«Обзор возможностей карты (тест)»** (`seed_sample_demo_scenario`). Витрина мультиэкрана: **«Мультиэкран: обзор возможностей»** (`seed_mosaic_demo_scenario`). Витрина трёх конструкторов: **«Три конструктора (витрина)»** (`seed_constructors_demo_scenario`).

Старые плоские сценарии при миграции автоматически раскладываются на этапы и программу.

---

## 1. Доступ

В админке Django: **Группы безопасности** → поле **«Сценарии демонстрации»**.

| Уровень | Что можно |
|---------|-----------|
| Чтение | Воспроизвести сценарий |
| Запись | Создавать и править сценарии в конструкторе |
| Запись+удаление | То же и удалять сценарии |

После обновления офлайн-установки выполните миграции (`migrate`) и команду `ensure_demo_scenario_permissions` (её вызывает `scripts\offline\post-update-offline.ps1`). Появятся таблицы сценариев, поле в группах, и право будет выдано тем, кто уже видит объекты на карте.

> При переходе на версию с этапами миграция переводит существующие шаги «После предыдущего» в режим «По щелчку». Гранулярность переключения сохраняется: где раньше был отдельный слайд, теперь отдельный этап. Флаг «Переключать этапы автоматически» у всех сценариев включён, поэтому старые сценарии продолжают играть сами.

## 2. Где находится

В меню **Инструменты** на карте (первые пункты):

- **Демонстрация: воспроизвести** — запуск сценария по умолчанию (если его нет — откроется конструктор).
- **Настроить демонстрацию…** — генеральный конструктор программы. Оттуда открываются **Этапы…** и **Мультиэкран…**.

Во время показа внизу экрана панель управления (поверх формуляра и справки по стране). Панель прячется, пока мышь не двигается, — клавиши работают и при скрытой панели. В панели: счётчик «Шаг программы X из Y», список блоков для быстрого перехода, пауза автопрокрутки, затемнение и выход. Справа на карте кнопка **«Меню»** открывает панели слоёв и объектов; **«Скрыть»** на доке убирает их обратно.

## 2.1. Управление с клавиатуры и пультом

Раскладка совместима с презентерами (Logitech, Kensington и подобные — они отправляют обычные клавиши).

| Клавиша | Действие |
|---------|----------|
| →, ↓, PageDown, Пробел, Enter | Следующий блок программы |
| ←, ↑, PageUp, Backspace | Предыдущий блок программы |
| Номер блока + Enter | Перейти к блоку (например, `7` `Enter`) |
| Home / End | Первый / последний блок |
| S | Пауза / продолжение автопрокрутки |
| B или `.` | Затемнить экран |
| W или `,` | Белый экран |
| F5 | Начать показ заново |
| Esc | Выход из демонстрации |

Кнопки пульта «вперёд» и «назад» шлют PageDown и PageUp, кнопка «чёрный экран» — точку или B. Отдельная настройка пульта не нужна: подключите приёмник и работайте.

**Как в PowerPoint:** если в текущем этапе ещё доигрывают такты, первое нажатие «вперёд» досрочно показывает этап целиком, второе переводит на следующий блок программы.

### Работа с картой во время показа

Демонстрация не прерывается, когда докладчик работает с картой: можно двигать карту, менять масштаб, кликать по объектам, закрывать формуляр. Пока идёт перетаскивание или зум, отсчёт времени внутри этапа приостанавливается, чтобы автопереход не выдёргивал камеру из-под руки; через полторы секунды после окончания он продолжается сам.

Следующий этап применяет свою камеру от текущего положения. Если у этапа камера в режиме «не двигать», карта останется там, куда её увёл докладчик.

## 3. Создать сценарий

Точка входа **Инструменты → Настроить демонстрацию…** открывает **генеральный конструктор**.

1. Слева нажмите **+ Новый**.
2. Задайте **название**. По желанию:
   - **Переключать автоматически** — значение по умолчанию для новых блоков программы. У каждого блока отдельно: переход по времени или по клику;
   - **Зацикливать показ** — после последнего блока начинается сначала;
   - **Запускать по умолчанию** — этот сценарий играет по кнопке «воспроизвести».
3. В шапке откройте **Этапы…** и соберите библиотеку видов карты (камера, объекты, текст). Этапы не обязаны стоять в программе — их можно назначать только на слоты мультиэкрана.
4. При необходимости **Мультиэкран…**: пресет раскладки и на каждый слот — один этап.
5. В центре генерального конструктора соберите **программу**: кнопки «+ Этап» и «+ Мультиэкран». У блока задаются переход **по времени** или **по клику**, длительность (0 = взять из этапа / пресета / анимации), вход и выход (`none`, `fade`, `blackout`, для мультиэкрана ещё `stagger`). У блока мультиэкрана: сетка, разворот выбранного слота в полный экран или свертывание обратно.
6. **Сохранить**. Затем **Воспроизвести**.

Порядок блоков меняется перетаскиванием. Блок можно дублировать или удалить. **Просмотр этапа**, **Просмотр пресета** и **Просмотр блока** закрывают конструктор и показывают только выбранный фрагмент — не весь сценарий.

## 4. Как устроен шаг

Каждый шаг — один инструмент плюс длительность, камера и (если нужно) анимация.

### Тайминг: этапы и элементы внутри них

Режим **«Начало»** внутри этапа определяет такт, а не слайд программы:

| Начало | Смысл |
|--------|-------|
| **Новый такт** | Шаг открывает новый такт внутри этапа |
| **После предыдущего** | Такт стартует по таймеру, когда отыграет предыдущий |
| **Вместе с предыдущим** | Идёт одновременно с предыдущим тактом |

Так один этап собирается из нескольких тактов. Например: перелёт камеры и вывод объектов «вместе с предыдущим», затем подпись «после предыдущего».

В конструкторе этапов такты сдвинуты; границы тактов видны в списке шагов. На временной шкале **генерального** конструктора рисуются блоки программы, а не отдельные шаги.

- **Длительность шага** — сколько шаг виден (от 0,5 с). Укажите в миллисекундах: 3000 = 3 секунды.
- **Не убирать содержимое предыдущего шага** — маркеры, зоны и слои прошлого шага остаются на карте.

Итоговая длительность этапа считается по тактам: элементы «вместе с предыдущим» не добавляют время.

### Переход назад

Стрелка «назад» возвращает на предыдущий этап и проигрывает его заново. Состояние карты (объекты, события, зоны, слои, тексты) пересобирается с начала сценария, поэтому накопленное «не убирать предыдущее» содержимое восстанавливается правильно, куда бы вы ни перешли. Прыжок по списку этапов из панели применяет состояние мгновенно, без перелёта камеры.

### Камера

- **Не двигать камеру**
- **Перелёт в точку** — широта, долгота, масштаб. Кнопка взять текущий вид карты подставляет координаты.
- **Вписать выбранное** — камера охватывает объекты / события / зоны / страну этого шага.

Длительность перелёта задаётся отдельно и обычно чуть короче длительности шага.

### Выбор содержимого

В пикере отметьте нужные элементы. Для объектов, событий, обстановки и зон сверху есть **фильтр стран** (поле с поиском, можно выбрать несколько). Пустой фильтр = все страны. Кнопки **Все** / **Ничего** действуют только на видимые строки.

**Оперативная обстановка** — одна на шаг. Во время показа открывается карточка подробностей; при анимации «смена состояний» текст и таймлайн совпадают с контуром на карте.

Если в шаге формуляра или справки выбрано несколько элементов, они показываются **по очереди** в рамках длительности шага. Дополнительно можно отметить **пункты** (разделы карточки) — демонстрация сразу проваливается в них. Пустой список пунктов = обзорная сетка.

На одной сцене открывается только одна такая панель: если в сцене и формуляр, и справка, побеждает **последний** шаг.

## 5. Инструменты

| Инструмент | Что происходит | Анимация |
|------------|----------------|----------|
| **Камера** | Только движение карты | нет |
| **Объекты** | Включаются маркеры выбранных объектов | проявление, мигание, мерцание, свечение, переливание цвета, колыхание |
| **События** | Показываются события | проявление, мигание |
| **Зоны действия** | Включаются типы зон. Рельеф (РЛС) во время показа не учитывается — зона рисуется кругом | проявление, раскрытие от центра |
| **Зоны затопления** | Зоны с признаком затопления | плюс направленное появление |
| **Оперативная обстановка** | Одна обстановка, полигон и карточка подробностей | проявление, смена состояний |
| **Слои карты** | Включаются слои (вода, дороги, …) | нет |
| **Формуляр объекта** | Та же карточка, что по клику на объект; можно сразу открыть выбранные пункты | нет |
| **Справка по стране** | Та же справка, что по клику на страну; можно сразу открыть выбранные пункты | нет |
| **Текст на карте** | Заголовок или подпись поверх карты | собственные эффекты входа и выхода |

Во время показа правки формуляра и справки отключены.

### Текст на карте

Инструмент **«Текст на карте»** добавляет титр или подпись. Обычно его ставят режимом «вместе с предыдущим» — тогда подпись появляется одновременно с объектами того же этапа.

**Положение.** Два способа привязки:

- **К экрану** — текст стоит в долях окна (например, по центру на 10 % высоты) и не двигается, когда докладчик крутит карту. Подходит для заголовков этапа.
- **К координатам** — текст стоит в точке карты и едет вместе с ней. Кнопка «Взять центр текущего вида карты» подставляет координаты. Флажок **«Масштабировать вместе с картой»** заставляет надпись расти и уменьшаться при зуме — как подпись на местности.

Дополнительно: сдвиг в пикселях по X и Y и фиксированная ширина блока (пусто — ширина по содержимому).

**Оформление.** Гарнитура, размер, насыщенность, курсив, подчёркивание, межстрочный и межбуквенный интервал, выравнивание, наклон блока и непрозрачность. Плюс:

- **цвет заливки** или **градиент** (два цвета и угол);
- **абрис** — обводка вокруг букв, цвет и толщина; хорошо читается поверх пёстрой карты;
- **подложка** — прямоугольник за текстом с прозрачностью, скруглением и отступом;
- **тень**.

Абрис и градиент можно включить вместе.

> В сборку входит только Roboto. Остальные гарнитуры (Arial, Times New Roman, Georgia, Courier New и т. д.) берутся из шрифтов операционной системы — на офлайн-сервере проверьте, что нужный шрифт установлен на машине докладчика.

**Эффекты входа:** без анимации, проявление, выезд (с выбором стороны), увеличение, из размытия, печатная машинка. Задаются длительность, задержка и сглаживание.

**Эффекты выхода:** без анимации, растворение, уезд, уменьшение, в размытие. Выход проигрывается, когда текст снимается следующим этапом.

Превью в редакторе конструктора показывает оформление. Чтобы поставить текст **прямо на карте**, нажмите **«Настроить на карте»**: конструктор временно скрывается, текст появляется в основном окне.

- Перетащите блок мышью или щёлкните по карте, чтобы выбрать место.
- В плавающей панели сверху задайте содержимое, цвет, гарнитуру, размер, насыщенность, курсив и привязку (к экрану или к координатам).
- **Готово** возвращает в конструктор с правками. **Отмена** (или Esc) откатывает изменения. Абрис, градиент, тень и эффекты входа/выхода по-прежнему настраиваются в инспекторе конструктора.

**Непрерывное действие** (если есть у эффекта): анимация повторяется до конца шага. Без флажка эффект проигрывается один раз. У объектов мигание, мерцание, свечение, переливание и колыхание по умолчанию непрерывные; проявление — один раз.

**Смена состояний** у обстановки листает ревизии. Задайте время на одно состояние (`per_state_ms`). Нужны обстановки с несколькими состояниями. Карточка подробностей идёт в ногу с контуром на карте.

## 5.1. Мультиэкран

Мультиэкран — отдельная библиотека пресетов. На каждый слот назначается **этап** из библиотеки, а не снимок объектов. В программу показа пресет попадает блоком типа «мультиэкран».

### Конструктор мультиэкрана

В генеральном конструкторе откройте **«Мультиэкран…»**:

1. Создайте пресет, выберите раскладку:
   - `1x2`, `2x1`, `1+2`, `2x2`, `2x3` (сетка 3×2, шесть ячеек), **`2+3`** (два экрана сверху, три снизу).
2. Задайте появление: **все сразу** или **постепенно** (`stagger_ms`). Отметьте слоты, которые **разрешено разворачивать** в полный экран.
3. Настройте анимацию разворота/свёртки слота:
   - **тип** — «Сразу на весь экран» (`stretch`, поведение по умолчанию) или «В центр, затем на весь экран» (`center_then_stretch`: сначала сдвиг к центру без изменения размера, потом растяжение; свёртка в обратном порядке);
   - **длительность** и **плавность** отдельно для разворота и для свёртки (`expand_ms` / `collapse_ms`, `expand_easing` / `collapse_easing`). Появление сетки по-прежнему задаётся полем «Длительность появления сетки» (`transition_ms`).
4. Для каждого слота выберите этап. Пустой слот остаётся заглушкой. Подпись нижней панели и повтор этапа (`loop`) задаются на слоте. **Просмотр пресета** показывает сетку без прогона всей программы.

Плитка на показе проигрывает назначенный этап (такты, камера, слои, эффекты, текст) облегчённым стеком: **растровые тайлы Leaflet без MapLibre** (меньше WebGL-контекстов). На развороте слота используется основная векторная карта. Формуляр и справка на сетке — компактная карточка в ячейке.

### Производительность мультиэкрана

- **Фоновый прогрев**: с нажатия «Старт» карты ближайшего пресета мультиэкрана поднимаются под основной картой. К блоку сетки показывается уже готовый результат; таймер блока ждёт готовности плиток.
- **Поочерёдный mount**: Leaflet-карты поднимаются пакетами по 2 слота в фоне, без скелетов на экране.
- **Единый mosaic-clock** (RAF): такты этапов на слотах синхронизируются; одинаковый `stage_id` (+ loop/delay) шарит один playback-state.
- **Page Visibility**: при скрытой вкладке clock и playback на паузе.
- Слоты сетки — `embedLite` (без MapLibre); живой MapLibre на сетке не сжимается до 0×0 и не пересобирает маркеры. На развороте — векторная карта.
- Дальнейшие идеи (видеостены, multi-viewport WebGL) — только если после этого на целевом железе всё ещё нестабильно.

### Программа

В генеральном конструкторе добавьте блок **«+ Мультиэкран»**. Действие блока:

- **Сетка** — все слоты рядом;
- **Развернуть экран** — слот едет в центр (при `center_then_stretch`), затем увеличивается до полного экрана; в конце один `invalidateSize`/`resize` карты;
- **Свернуть в сетку** — обратная анимация (scale + translate на fullscreen-layout). Сетка при этом остаётся видимой под рамкой.

У блоков **Развернуть** / **Свернуть** можно переопределить тип анимации, длительность и плавность относительно пресета («как в пресете» — взять значения из конструктора мультиэкрана).

Вход `stagger` показывает ячейки по очереди, `fade` — проявление сетки, `blackout` — затемнение. Выход снимает сетку и возвращает основную карту. Подряд идущие блоки одного пресета (сетка → разворот → свёртка) не пересоздают сетку.

Переход к следующему блоку: **по времени** или **по клику** (стрелка / пробел / пульт).

### Показ

- Каждая плитка **проигрывает назначенный этап**: такты, камера, маркеры, события, зоны, слои, текст и эффекты. На карту попадают только объекты и слои этого этапа (срез каталога). Базовая подложка на сетке — растр; на развороте — векторная карта.
- Формуляр и справка по стране на сетке — **компактная карточка в ячейке** (имя объекта или страны; при выбранных пунктах — заголовок пункта). Полноразмерные панели открываются только на **развороте** слота.
- Флаг `loop` на слоте **повторяет этап** с первого такта; непрерывные эффекты последнего такта не гасятся, пока слот на экране.
- У каждой ячейки нижняя панель с названием.
- Основная карта скрыта, пока играет сетка. При **развороте** цветная рамка слота либо сразу растёт до полного экрана (`stretch`), либо сначала едет в центр монитора и затем растягивается (`center_then_stretch`); **свёртка** выполняет те же фазы в обратном порядке. Пока идёт разворот, плитки сетки на паузе.
- Живой показ этапа вне мультиэкрана — когда в программе играет блок `stage`.

## 6. Рекомендации по сценарию

1. Начните с **камеры** (общий план), затем приближение.
2. Покажите **объекты**, затем **формуляр** тех же объектов.
3. **Справка по стране** — после того, как зритель видит регион.
4. **События** и **зоны** удобно ставить с «не убирать предыдущее», чтобы маркеры остались.
5. **Обстановка со сменой состояний** — отдельные шаги; на шаг открывается одна обстановка и карточка подробностей.
6. Для доклада у блока выберите переход **по клику**. Собирайте этапы так, чтобы каждый отвечал одной мысли: перелёт, объекты и подпись в одном этапе.
7. Подпись к этапу ставьте режимом **«вместе с предыдущим»**, тогда она появится одновременно с содержимым.
8. В тестовом сценарии шаг длится **4 с**. Для показа зрителям часто достаточно 3–4 с.
9. Сохраняйте сценарий до показа. Несохранённый черновик при закрытии конструктора пропадёт.

### Три конструктора (витрина)

Команда: `seed_constructors_demo_scenario --replace --default`.

Сценарий для показа новой иерархии. В библиотеке 9 этапов, в программе 8 блоков:

| Блок программы | Что смотреть |
|----------------|--------------|
| Титул (вход fade) | Подпись на общем плане |
| Этап из нескольких тактов | Камера + объекты + текст вместе, затем приближение — один слайд, несколько тактов |
| Мультиэкран 2+3 (вход stagger) | Два экрана сверху, три снизу; слоты берут этапы из библиотеки |
| Разворот слота A | Ячейка «Кавказ» увеличивается в полный экран |
| Свёртка в сетку | Обратная анимация в позицию ячейки |
| Кавказ (вход blackout) | Тот же этап, что на слоте A, теперь на живой карте |
| Пауза докладчика | Переход по клику, даже если остальные блоки идут по времени |
| Финал (вход fade) | Закрывающий титр |

Этапы «ГЭС / Азия», «События», «РЛС», «Общий план» в программе не стоят — только на слотах. Так видно, что библиотека переиспользуется.

Как показывать конструктор:

1. **Этапы…** — список шаблонов, внутри «Этап из нескольких тактов» несколько шагов.
2. **Мультиэкран…** — раскладка «Два сверху, три снизу», на ячейках названия этапов.
3. Генеральный конструктор — таймлайн из шести блоков, справа вход/выход и «ждать докладчика».
