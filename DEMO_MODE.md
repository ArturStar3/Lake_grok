# Демонстрация возможностей карты

Сценарий демонстрации — это последовательность шагов (как слайды): камера, объекты, события, зоны, формуляр, справка по стране и т.д. Сценарии хранятся на сервере и доступны всем, у кого есть право **«Сценарии демонстрации»**.

Готовый тестовый сценарий: **«Обзор возможностей карты (тест)»**, шаг 4 секунды (команда `seed_sample_demo_scenario`).

---

## 1. Доступ

В админке Django: **Группы безопасности** → поле **«Сценарии демонстрации»**.

| Уровень | Что можно |
|---------|-----------|
| Чтение | Воспроизвести сценарий |
| Запись | Создавать и править сценарии в конструкторе |
| Запись+удаление | То же и удалять сценарии |

После обновления офлайн-установки выполните миграции (`migrate`) и команду `ensure_demo_scenario_permissions` (её вызывает `scripts\offline\post-update-offline.ps1`). Появятся таблицы сценариев, поле в группах, и право будет выдано тем, кто уже видит объекты на карте.

---

## 2. Где находится

В меню **Инструменты** на карте (первые пункты):

- **Демонстрация: воспроизвести** — запуск сценария по умолчанию (если его нет — откроется конструктор).
- **Настроить демонстрацию…** — конструктор сценариев.

Во время показа внизу экрана панель управления (поверх формуляра и справки по стране):

| Клавиша | Действие |
|---------|----------|
| Пробел | Пауза / продолжить |
| ← / → | Предыдущий / следующий шаг |
| Esc | Выход из демонстрации |

Клик по карте или закрытие формуляра / справки крестиком ставит показ на паузу.

---

## 3. Создать сценарий

1. **Инструменты → Настроить демонстрацию…**
2. Слева нажмите **+ Новый**.
3. Задайте **название**. По желанию:
   - **Зацикливать показ** — после последнего шага начинается сначала;
   - **Запускать по умолчанию** — этот сценарий играет по кнопке «воспроизвести» (остальные снимаются с «по умолчанию»).
4. В центре добавьте шаги кнопками инструментов (Камера, Объекты, События, …).
5. Справа настройте выбранный шаг.
6. **Сохранить**. Затем **Воспроизвести** или закройте конструктор и запустите из меню инструментов.

Порядок шагов меняется перетаскиванием или стрелками. Шаг можно дублировать или удалить. **Просмотр шага** в инспекторе проигрывает только этот шаг.

---

## 4. Как устроен шаг

Каждый шаг — один инструмент плюс длительность, камера и (если нужно) анимация.

### Тайминг

- **Длительность шага** — сколько шаг виден (от 0,5 с). Укажите в миллисекундах: 3000 = 3 секунды.
- **Начало:**
  - «После предыдущего» — шаг идёт следующим слайдом;
  - «Вместе с предыдущим» — шаг показывается одновременно с предыдущим (одна «сцена»).
- **Не убирать содержимое предыдущего шага** — маркеры, зоны и слои прошлого шага остаются на карте.

Итоговая длительность сценария считается по сценам: шаги «вместе с предыдущим» не добавляют время.

### Камера

- **Не двигать камеру**
- **Перелёт в точку** — широта, долгота, масштаб. Кнопка взять текущий вид карты подставляет координаты.
- **Вписать выбранное** — камера охватывает объекты / события / зоны / страну этого шага.

Длительность перелёта задаётся отдельно и обычно чуть короче длительности шага.

### Выбор содержимого

В пикере отметьте нужные элементы. Для объектов, событий, обстановки и зон сверху есть **фильтр стран** (поле с поиском, можно выбрать несколько). Пустой фильтр = все страны. Кнопки **Все** / **Ничего** действуют только на видимые строки.

**Оперативная обстановка** — одна на шаг. Во время показа открывается карточка подробностей; при анимации «смена состояний» текст и таймлайн совпадают с контуром на карте.

Если в шаге формуляра или справки выбрано несколько элементов, они показываются **по очереди** в рамках длительности шага. Дополнительно можно отметить **пункты** (разделы карточки) — демонстрация сразу проваливается в них. Пустой список пунктов = обзорная сетка.

На одной сцене открывается только одна такая панель: если в сцене и формуляр, и справка, побеждает **последний** шаг.

## 5. Инструменты

| Инструмент | Что происходит | Анимация |
|------------|----------------|----------|
| **Камера** | Только движение карты | нет |
| **Объекты** | Включаются маркеры выбранных объектов | проявление |
| **События** | Показываются события | проявление, мигание |
| **Зоны действия** | Включаются типы зон. Рельеф (РЛС) во время показа не учитывается — зона рисуется кругом | проявление, раскрытие от центра |
| **Зоны затопления** | Зоны с признаком затопления | плюс направленное появление |
| **Оперативная обстановка** | Одна обстановка, полигон и карточка подробностей | проявление, смена состояний |
| **Слои карты** | Включаются слои (вода, дороги, …) | нет |
| **Формуляр объекта** | Та же карточка, что по клику на объект; можно сразу открыть выбранные пункты | нет |
| **Справка по стране** | Та же справка, что по клику на страну; можно сразу открыть выбранные пункты | нет |

Во время показа правки формуляра и справки отключены.

**Непрерывное действие** (если есть у эффекта): анимация повторяется до конца шага. Без флажка эффект проигрывается один раз.

**Смена состояний** у обстановки листает ревизии. Задайте время на одно состояние (`per_state_ms`). Нужны обстановки с несколькими состояниями. Карточка подробностей идёт в ногу с контуром на карте.

## 6. Рекомендации по сценарию

1. Начните с **камеры** (общий план), затем приближение.
2. Покажите **объекты**, затем **формуляр** тех же объектов.
3. **Справка по стране** — после того, как зритель видит регион.
4. **События** и **зоны** удобно ставить с «не убирать предыдущее», чтобы маркеры остались.
5. **Обстановка со сменой состояний** — отдельные шаги; на шаг открывается одна обстановка и карточка подробностей.
6. В тестовом сценарии шаг длится **4 с**. Для показа зрителям часто достаточно 3–4 с.
7. Сохраняйте сценарий до показа. Несохранённый черновик при закрытии конструктора пропадёт.

## 7. Тестовый сценарий на офлайн-сервере

После загрузки образов и `migrate`:

```powershell
docker compose -f docker-compose.yml -f docker-compose.server.yml exec -T backend python manage.py seed_sample_demo_scenario --replace
```

Создаётся (или перезаписывается) сценарий **«Обзор возможностей карты (тест)»**, ставится по умолчанию, зациклен. Каждый шаг — 4 секунды. В сценарии есть зоны РЛС без рельефа, непрерывное раскрытие, одна обстановка с карточкой и проваливание в пункты формуляра/справки. Нужны объекты, события и обстановки в базе (тестовые данные QA или ваши). Если каких-то сущностей нет, соответствующие шаги сохранятся с пустым выбором.

Запуск: **Инструменты → Демонстрация: воспроизвести**.
