# Конвертер координат InfoLake (DD ↔ DMS)

Отдельная утилита. Код InfoLake не изменяет.

## Система координат

В InfoLake координаты — **WGS 84 / EPSG:4326**, **десятичные градусы**:

- широта (`lat`) −90…90
- долгота (`lng`) −180…180
- 6 знаков после запятой (`55.751244`)

Карта рисуется в Web Mercator (EPSG:3857), но все точки, формы и GeoJSON хранятся и вводятся в lat/lng WGS 84. Это **не** СК-42 и не Гаусса–Крюгера: конвертер меняет только запись (десятичные градусы ↔ градусы-минуты-секунды) в той же системе.

## Запуск exe

Собранный файл: `dist/InfoLakeCoordConverter.exe` (Python на целевой машине не нужен).

Сборка на Windows:

```powershell
cd converter
.\build.ps1
```

Нужен Python 3.10+ в PATH.

Запуск из исходников:

```powershell
cd converter
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
.\venv\Scripts\python app.py
```

## Одна точка

Вкладка «Одна точка»: вставьте широту и долготу, выберите направление.

Примеры DMS:

Пишите **градусы, минуты, секунды** в таком виде:

`Г°ММ'СС.ссс" полушарие`

| | Основной вид | Без значков ° ' " | По-русски |
|--|----------------|-------------------|-----------|
| Широта | `55°45'04.478" N` | `55 45 04.478 N` | `55 45 04.478 с.ш.` |
| Долгота | `37°37'06.323" E` | `37 37 06.323 E` | `37 37 06.323 в.д.` |

Можно полушарие впереди: `N55°45'04.478"`.

- широта: **N** / с.ш. = север, **S** / ю.ш. = юг
- долгота: **E** / в.д. = восток, **W** / з.д. = запад
- минуты и секунды — от 0 до 59; секунды можно с тысячными

Юг и запад в десятичных градусах — отрицательные числа (`-33.868800`).

Готовый файл-образец: [sample_coords.xlsx](sample_coords.xlsx) (лист «образец» + строка на листе `coords`). Тот же образец создаёт кнопка «Сохранить шаблон xlsx».

## Пакет xlsx

Вкладка «Пакет xlsx»: можно выбрать несколько файлов. На каждый пишется соседний `*_converted.xlsx` (или в указанную папку). Исходные колонки не удаляются.

Заголовки (регистр не важен):

| Роль | Имена колонок |
|------|----------------|
| широта DD | `lat`, `latitude`, `широта` |
| долгота DD | `lng`, `lon`, `longitude`, `долгота` |
| широта DMS | `lat_dms`, `широта_dms` |
| долгота DMS | `lng_dms`, `долгота_dms` |

- DD → DMS: нужны `lat` и `lng`; добавляются `lat_dms` и `lng_dms`.
- DMS → DD: нужны `lat_dms`/`lng_dms` или `lat`/`lng` с текстом DMS; пишутся `lat` и `lng` с 6 знаками.

Ошибочные строки получают текст в колонке `error`, остальные строки того же файла обрабатываются.

Кнопка «Сохранить шаблон xlsx» создаёт файл с колонками `lat`, `lng`, `lat_dms`, `lng_dms` и примером Москвы.
